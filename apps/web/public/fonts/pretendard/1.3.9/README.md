# Pretendard 1.3.9

This directory contains the unmodified variable dynamic-subset web assets from
the official `pretendard@1.3.9` npm package (`dist/web/variable/`). Unlike the
`pretendard-jp` dynamic subset, this base build carries the full composed-Hangul
syllable block, so it is the family used for Korean text (`:lang(ko)`).

- Upstream: https://github.com/orioncactus/pretendard/tree/main/packages/pretendard
- License: SIL Open Font License 1.1; see `LICENSE.txt` in this directory.
- CSS family name: `Pretendard Variable`.

The version is part of the public URL so these files can be served with an
immutable cache policy. Add a new versioned directory instead of replacing the
contents in place when upgrading.
