# Noto Sans SC (variable) 5.3.0

This directory contains the unmodified variable dynamic-subset web assets from
the `@fontsource-variable/noto-sans-sc@5.3.0` npm package (`wght.css` + `files/`).
Pretendard covers no Simplified Chinese hanzi (its Han is the JIS set in Japanese
forms), so Simplified Chinese text (`:lang(zh-CN)`) uses this family instead.

- Upstream: https://github.com/fontsource/font-files (Noto Sans SC, Google Fonts)
- License: SIL Open Font License 1.1; see `LICENSE` in this directory.
- CSS family name: `Noto Sans SC Variable`.

The version is part of the public URL so these files can be served with an
immutable cache policy. Add a new versioned directory instead of replacing the
contents in place when upgrading.
